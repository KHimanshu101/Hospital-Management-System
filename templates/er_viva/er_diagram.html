Database Schema Dictionary & Relationships
Core Primary & Foreign Keys:
  • doctors.department_id → departments.id (RESTRICT)
  • appointments.patient_id → patients.id (RESTRICT)
  • appointments.doctor_id → doctors.id (RESTRICT)
  • admissions.bed_id → rooms_beds.id (RESTRICT)
  • bill_items.bill_id → bills.id (CASCADE)
  • prescription_items.prescription_id → prescriptions.id (CASCADE)
Key Constraints & Multi-Column Rules:
  • rooms_beds: UNIQUE constraint on (room_number, bed_number)
  • appointments: UNIQUE constraint on (doctor_id, appointment_date, appointment_time)
  • medicines: CHECK constraint enforcing quantity >= 0
  • doctors: CHECK constraint enforcing consultation_fee >= 0
